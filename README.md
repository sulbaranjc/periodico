# JC DEPORTES 📰

Periódico Digital de Deportes - Sitio web responsivo y moderno

## 📋 Descripción

Periódico deportivo digital con diseño profesional inspirado en medios de comunicación como El Mundo. Incluye secciones de Champions League, artículos sobre equipos españoles y contenido multimedia.

## ✨ Características

- **Diseño Responsivo**: Optimizado para desktop, tablet y mobile
- **Header Profesional**: Navegación completa, buscador y fecha
- **Artículos Destacados**: Artículo principal con sidebar de noticias relacionadas
- **Galería de Artículos**: Grid de 4 columnas adaptativo
- **Publicidad Lateral**: Dos sidebars con anuncios profesionales
- **Estilos Modernos**: Tipografía elegante (Georgia serif), colores profesionales
- **Optimizado**: Carga rápida, imágenes optimizadas

## 🛠️ Tecnologías

- HTML5 semántico
- CSS3 con media queries
- Diseño mobile-first
- GitHub Pages para hosting

## 📱 Breakpoints Responsivos

- **Mobile**: hasta 480px
- **Tablet**: 768px - 1199px
- **Desktop**: 1200px+
